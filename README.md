# Fret Helper

App para pintar escalas y acordes sobre el diapasón de una guitarra, identificarlos y relacionarlos entre sí. Hoy es un POC en React + TypeScript + Vite + Redux.

- Estado actual del código: [`docs/estado-actual.md`](docs/estado-actual.md)
- Alcance del MVP (en discusión): [`docs/mvp-alcance.md`](docs/mvp-alcance.md)

## Desarrollo

```bash
npm install
npm run dev
```
